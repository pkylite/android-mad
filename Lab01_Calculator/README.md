# Lab 01: Calculator App

## Overview
This lab covers the basics of Android UI layout, state management, and event handling. You will build a functional calculator that performs basic arithmetic operations.

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division.
- Live result preview as you type.
- Final result display on clicking the equals button.
- Support for parentheses and floating-point numbers.
- Dynamic input validation.

## Concepts Covered
- **View Binding**: Interacting with UI elements from code.
- **UI Layouts**: Using `LinearLayout` and `TableLayout`.
- **Event Handling**: Responding to button clicks.
- **Expression Parsing**: Integrating `mXparser` for mathematical evaluation.
- **Resources**: Using `strings.xml` and `colors.xml` for clean, themeable code.

## How to Run
1. Open this folder in Android Studio.
2. Build and run on an emulator or physical device.
